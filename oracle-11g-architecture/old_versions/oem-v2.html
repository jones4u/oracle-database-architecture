Architecture

The agent collects from the target and uploads to the OMS. The OMS writes to the repository and retrieves the data that the console displays.

  • 11g targetDatabase instance or host being monitored
  • Management AgentCollects data using the target plug-in
  • Management ServiceReceives uploads and serves the console
  • Management RepositoryStores management, metric and incident data
  • Cloud Control consoleDisplays target evidence to the operator
  • Incident rulesRoute configured events and notifications
