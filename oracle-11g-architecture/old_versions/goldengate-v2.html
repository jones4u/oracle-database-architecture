Architecture

Source redo → Extract → local trail → pump → Collector → remote trail → Replicat → target rows.

  • ManagersManage classic groups on each installation
  • Source 11g databaseRedo records for changes to mapped tables
  • Primary ExtractCaptures changes and tracks transaction boundaries
  • Local trailDurable capture output on the source host
  • Data pumpReads the local trail and sends records
  • Target CollectorReceives records and writes the remote trail
  • Remote trailOrdered input for target delivery
  • ReplicatMaps and applies trail transactions
  • Target databaseCommits applied changes and checkpoints
